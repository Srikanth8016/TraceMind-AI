# TraceMind AI

> AI-powered software incident investigation platform.

## Milestone 1 — Project Skeleton

A minimal, production-shaped FastAPI service with a `/health` endpoint and a
full pytest suite. Nothing more, nothing less.

---

## Project structure

```
tracemind-ai/
├── app/
│   ├── __init__.py       # makes `app` an importable package
```

## Setup

### 1 — Create and activate a virtual environment

```powershell
# Windows (PowerShell)
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

```bash
# macOS / Linux
python3 -m venv .venv
source .venv/bin/activate
```

> **Tip:** your shell prompt will show `(.venv)` once the environment is active.

### 2 — Install dependencies

```powershell
python -m pip install --upgrade pip
python -m pip install -r requirements.txt
```

## Running the server

```powershell
uvicorn app.main:app --reload
```

- `app.main` — Python module path (`app/main.py`)
- `app` — the `FastAPI()` instance inside that module
- `--reload` — auto-restarts on file changes (development only)

The server listens on **http://127.0.0.1:8000** by default.

| URL | Description |
|-----|-------------|
| `GET /health` | Liveness probe |
| `GET /docs` | Interactive Swagger UI |
| `GET /redoc` | ReDoc API docs |

### Quick smoke-test (curl / PowerShell)

```powershell
Invoke-RestMethod http://127.0.0.1:8000/health
```

Expected response:

```json
{"status": "healthy", "service": "tracemind-ai"}
```

## How a request reaches the endpoint

```
HTTP client
    │
    │  GET /health
    ▼
Uvicorn (ASGI server)          ← handles raw TCP / HTTP parsing
    │
    ▼
FastAPI (ASGI app)             ← routes the request by method + path
    │
    ▼
health_check() in main.py      ← your function executes
    │
    ▼
FastAPI serialises return value to JSON
    │
    ▼
HTTP 200 {"status":"healthy","service":"tracemind-ai"}
    │
    ▼
HTTP client
```

**Key insight:** FastAPI is a *framework* built on top of Starlette (another
ASGI framework). Uvicorn is the *server* that speaks HTTP and feeds raw ASGI
events into FastAPI. Your code only ever sees clean Python objects — FastAPI
handles serialisation, validation, and OpenAPI generation automatically.
